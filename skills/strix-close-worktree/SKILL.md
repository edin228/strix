# Strix close worktree

Resolve the exact workspace, creation base, reviewed tip, owned resources, and
requested terminal outcome. Read project lifecycle procedures. Track merge,
runtime or database reconciliation, cleanup, and branch deletion authorities
separately. Reuse existing authorization; finish safe preparation before asking
for any missing authority.

Verify current validation, review, and required safety evidence. Use the
project's trusted closeout checks when available. Honor only permitted explicit
waivers and list every omitted lane; a waiver is never a passing result.
Source-only tooling requires its own checks, not invented application evidence.

If integration remains requested and incomplete, use strix-ship when installed
or the protected project merge procedure. Do not replay a completed merge.
Prove one disposition through fresh target ancestry, accepted squash equivalence,
or another explicitly selected project disposition before destructive cleanup.
A queued, failed, or merely closed PR is not merge proof.

For authorized local reconciliation, derive affected services and schema work
from the durable creation-base-to-integration diff. Follow the documented
migration and runtime owner, preserving recovery evidence. Report deferred or
failed reconciliation explicitly. Do not reset a dirty normal checkout or take
over its running processes to make the local branch match the remote.

Retire only the clean, identified workspace and owned resources through
strix-worktree when installed or project removal procedures. Verify dirty and
untracked state again immediately before removal. Retain branches and evidence
unless their deletion is separately authorized. Never infer production release
from integration or cleanup.

After partial success, inspect the existing phase state and resume only the
unfinished step. Do not roll back a merge or repeat a destructive action to
obtain a cleaner report. Return integration proof, reconciliation result,
removed and retained resources, branch, and exact recovery action if blocked.
